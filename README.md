# AppBlocking
Screen Time & Digital Wellbeing App – SwiftUI

A modern Digital Wellbeing and Productivity Management solution built using Apple’s latest Screen Time frameworks in SwiftUI.

This project demonstrates how to build privacy-focused parental control and productivity features on iOS using:

✅ FamilyControls
✅ ManagedSettings
✅ DeviceActivity
✅ Screen Time API
✅ SwiftUI
✅ Map & Location Integration

🚀 Features
📱 App & Website Monitoring
Select apps and websites using Apple’s FamilyControls picker
Monitor usage activity
Track focus sessions and restricted apps
